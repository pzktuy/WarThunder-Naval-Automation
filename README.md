战争雷霆海战自动化

一个用于战争雷霆海战的实验性自动化脚本，基于[战争雷霆苹果派助手](https://github.com/JerryLikePie/WT-ApplePie-Assistant)开发，但很显然已经经过了[Adobe_Hit_乐](https://space.bilibili.com/547325222)的爆改。仅用作实验自动驾驶，无法刷钱刷分（并非）。 如果遇到bug或者有改进想法欢迎b站联系。

## 免责声明

在战争雷霆中使用自动化脚本违反游戏服务条款，存在账号被封禁的风险（尤其是连续长时间运行，为此脚本设置了定时关闭功能）

(我的账号曾因为连续数天运行老版本数天，已在2026年8月健康行动中被封禁！)

## 功能

* 全自动海战操作。

* 自动航行与避障。

* 自动识别搁浅及驶出小地图的情况。

* 自动跟踪目标。

* 根据游戏内测距仪计算并跟踪提前量。

* 可选的银狮收益统计功能（需要安装 Tesseract-OCR引擎并添加环境变量）。

* 定时(30000s后)停止进入新对局(如果连续运行时间过长会被封号)

##需要进行的战争雷霆设置

之前更新了脚本但忘了更新设置，请务必阅读所有设置。不过这个脚本还没有在其他电脑上正式运行过，希望bug别太多吧……

▶图像设定：

	分辨率：1270x720

	显示模式：窗口模式

	UI大小：100%

▶界面语言：中文

▶游戏选项->海战设置：

	弹道跟踪视角：否

▶按键设置->海战：

	（建议在设置按键前恢复默认设置。在按键设置内点击“全部清除”；然后选择按键配置；“仅键盘鼠标（简化）”，点击“选择布局”）

	目标跟踪（海战）：=（单击）

▶队列设置：在队列中放入一条船并选中

▶游戏模式：海战历史


将游戏处于车库（船坞）的界面下，打开终端进入到（VScode打开文件夹）autoscriptVxxx文件夹下，运行autoscriptVxxx.py 当图形界面弹出后设定脚本参数，或点击“驱逐舰”“巡洋舰”等模板设置（无需精确设置，长或短均能运行）。设置好后点击“运行”，然后切换回战争雷霆界面即可。
